# Enterprise E-Commerce Platform

A full-stack, enterprise-grade e-commerce platform built using the MERN stack,
focused on secure authentication, scalable backend services, and cloud deployment.

## Overview
This project was developed for enterprise use and implements core e-commerce
functionality with a strong emphasis on security, reliability, and maintainability.

## Key Features
- Secure user authentication with Email/Password and Google OAuth 2.0
- JWT-based authorization and protected APIs
- Product, cart, order, and user profile management
- Secure payment workflow integration using Razorpay
- Modular RESTful backend architecture
- Cloud-ready design with AWS services and Infrastructure as Code

## Tech Stack
- **Frontend:** React
- **Backend:** Node.js, Express
- **Database:** MongoDB
- **Authentication:** Google OAuth 2.0, JWT
- **Cloud & DevOps:** AWS (S3, Lambda), Terraform
- **Payments:** Razorpay

## Architecture Highlights
- Clean separation of frontend and backend services
- Secure authentication and middleware-based access control
- Scalable backend APIs designed for production use
- Infrastructure provisioning using Terraform

## Notes
This repository represents a real-world enterprise project.
